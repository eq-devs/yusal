- 未运行 Android release APK 或 iOS simulator 构建。
- 未完成同设备 profile 模式下 100 个作品的帧耗时对照，因此不宣称提速比例。
- 浏览器验证只覆盖上述入口，不代表游客、设计、发布、报价、合作全部端到端验收完成。
- 布局矩阵针对首页，不代表所有页面、键盘弹出状态及全量三语文案均已验收。
- 原计划中编辑器工具入口与选择提示的广泛调整未实施；本轮聚焦保存可靠性和状态提示。
- 后端仍为演示实现，未新增生产账号、真实云备份、支付或其他后端能力。

## 继续设备验收

在可正常启动模拟器的环境，从项目根目录执行：

```sh
flutter devices
bash tool/validate_optimization.sh <模拟器设备ID>
```

脚本依次进行静态检查、全量测试、Web 构建及两组设备集成测试；任一步失败即停止。之后仍需手工检查键盘、大字体、导入导出和报价合作流程，并做 profile 性能测量。

## 图纸查看补充（2026-11-04）

作品详情、需求详情和公开分享页增加「设计图纸 → 打开图纸」。新发布作品或从设计发布的需求保存去除 extras（私人备注、规格、预算等）的固定几何版本；查看器支持楼层切换、尺寸、拖动缩放和重置。查看不进入编辑器，也不创建或覆盖本地项目。

公开作品的快照不再依赖关联需求才能读取；详情按作品或需求上下文读取，需求「公开平面图」关闭后不返回其图纸数据。旧附件仅有图片时兼容图片查看，没有附件时明确提示；演示种子内容未虚构补画图纸。

本轮全量 **309 项测试通过**，包含公开独立作品读取、只读入口、缩放控件、隐藏图纸入口及快照几何保留与私人 extras 排除。设备验收限制仍同上。
