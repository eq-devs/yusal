# 只分享、求点评：方案 v5

> 背景：很多人画了房子只想发出来，听听大家怎么说，并不打算马上找人盖。这条路以前被当成"找人"的附属，现在要让它成为正经的一条路，并且随时能顺滑地接回"找人 → 报价 → 施工"。

## 一句话

**发布时先说清楚"我想要什么"：听意见，还是找人盖。** 听意见的房子，页面围绕点评组织；想盖的时候一键切换，原来的点评和图纸都带过去。

## 1. 发布：先选意图

发布页顶部两张卡片，二选一（以后可改）：

| | 听听大家意见（默认） | 准备盖，找施工方 |
|---|---|---|
| 卡片角标 | 求点评 | 正在找施工方 |
| 房子页主按钮（访客） | 写点评 | 去报价 / 私信 |
| 发现页 | 出现在"求点评"筛选里 | 出现在"正在找施工方"筛选里 |

选"听意见"时，可以勾选 **最多 3 个想请大家重点看的方面**：布局、采光朝向、造价、结构、外观、保暖。这些会显示在房子页顶部"作者想听听"，点评时也能直接选。

## 2. 点评：有主题、能回复、作者能标"有用"

- 每条点评可以选一个主题（来自上面的方面），房子页可以按主题看。
- 整体打分保留（1–5 星，每人一个）；作者自己不能给自己打分。
- **可以回复**（一层）：作者答疑、别人补充，都挂在原点评下面。
- **作者可以标"有用"**：被标的点评置顶，显示"作者觉得有用"。点评人会收到通知。
- 有名片的工人、施工队、工程师，名字旁显示身份（已有），让懂行的意见更显眼。

## 3. 作者这一侧

- **我的房子**：发布过、有点评的设计也会出现在"我的房子"里（阶段：设计），下一步写"3 条新点评"。点进去直接看点评。
- 新点评、新回复、被标有用，都有通知。
- 房子页底栏（作者自己看）：
  - 听意见阶段：左边"12 条点评 · 3 条有用"，右边"准备开建？为它找人"。
  - 点一下会把意图切到"找施工方"，并进入招人流程，工程量从设计里带出来。

## 4. 发现页

- 房子 tab 的筛选增加 **"求点评"**，和"正在找施工方"并列。
- 卡片角标：求点评 / 正在找施工方，一眼区分。
- 卡片下方显示"5 条点评"，求点评的房子把点评数放在前面。

## 5. 和闭环怎么接

```
画设计 → 发布（听意见）→ 收点评 → 改设计 → 准备开建？→ 找人 → 报价 → 施工 → 完工
                    ↘ 别人"用这套开始"→ 他自己的房子
```

- 听意见的房子，别人照样可以"用这套开始"，作者会看到"被 N 人拿去改"。
- 切到"找施工方"后，点评保留在房子页，施工方报价前能看到大家的意见。

## 这次先做 / 之后再做

**这次做：** 发布意图 + 想听的方面；点评主题、回复、标有用；发现页"求点评"筛选和角标；我的房子收进有点评的设计；作者底栏"准备开建？"一键切换；相关通知。

**之后再做：** 根据点评改版（第 2 版图纸、"改了什么"说明、点评标注针对哪一版）。需要从本地设计重新生成快照并保留旧版，改动面较大，等这一版验收后再做。
