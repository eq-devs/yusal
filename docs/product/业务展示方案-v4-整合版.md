# Yusal 业务展示方案 v4（整合版）

日期：2026-11-04 · 状态：已在 App 中实现第 8 节第 1–8 项（mock 后端），见文末“实现记录” · 取代 [v3](业务展示逻辑方案-v3.md)（v3 的页面线框仍有效，本版只写新增和改动）
依据：产品文档 v2、v3 方案、[中国同类平台调研](../research/中国同类平台调研.md)（土巴兔、齐家、酷家乐、好好住、鱼泡、吉工家、图纸之家、易盖房、化化网等）

## 1. 一句话

**自己画（或从别人的图纸开始）一栋房子 → 按同一张工程量清单找人比价 → 按节点施工、验收、记工 → 建成后变成别人能复用的图纸。**

中国市场被切成了几块：图纸库、装修撮合、工人招工、记工工具、内容社区，各有一家头部，没有一家把四件事连起来。Yusal 用“一栋房子”把它们串成一个闭环。

## 2. 业务总图（飞轮）

```
        ┌──────────── ① 图纸库（发现 · 房子） ◄────────────┐
        │   公开设计：面积 / 层数 / 估价 / 建成实景         │
        │   “用这套开始” 复制到我的房子                    │
        ▼                                                 │
  ② 我的房子：自己画 / 改别人的图 → 自动工程量清单        │
        │                                                 │
        ▼                                                 │
  ③ 找人：按阶段发需求（基础 / 主体 / 屋顶 / 水电 / 装修） │
        │   也可以不画图，直接找人                        │
        ▼                                                 │
  ④ 比价：所有师傅在同一张清单上逐项报价，并排对比        │
        │                                                 │
        ▼                                                 │
  ⑤ 合作约定：分节点（金额 + 验收标准 + 日期）            │
        │                                                 │
        ▼                                                 │
  ⑥ 施工：师傅每天记工 / 打卡 + 拍照；节点到了申请验收，  │
        │   业主确认，记录挂在房子进度上                  │
        ▼                                                 │
  ⑦ 完工：双向评价 → 师傅作品集自动生成 → 房子页显示     │
        “已建成 · 谁建的 · 实际花费”                      ─┘
```

每一步都在“我的房子”里有一个位置，在房子页上有一个公开的痕迹，所以业主、师傅、访客看的是同一条线。

## 3. 借鉴什么、做得更好在哪、避开什么

| 来源 | 他们怎么做 | Yusal 怎么做（更好的地方） |
| --- | --- | --- |
| 图纸之家、住宅在线、易盖房（图纸库获客） | 卖现成图纸，几百元一套，靠图纸吸流量 | 公开设计就是图纸库，免费；**“用这套开始”**复制后可以自己改、马上出工程量和估价，再一键找人。图纸作者在被复用时得到署名和通知 |
| 好好住（内容社区，2025 年停运） | 看案例、找设计师，内容和交易脱节 | 每个房子页都直接连着“在招谁”“谁在建”“用这套开始”，内容就是交易入口，不做纯晒图社区 |
| 土巴兔（各装企各报各的） | 装企上门后各自报价，没法比 | **统一工程量清单报价**：师傅只能在 Yusal 生成的清单上逐项填单价，业主看到一张对比表，每行标出最高 / 最低；单位或范围不同的明确提示不可比 |
| 土巴兔装修保、易盖房、化化网（节点托管付款） | 钱放平台 / 银行，按“基础—封顶—抹灰—竣工”验收后放款 | MVP 先做**节点验收记录**，不碰钱：合作约定按节点写金额，师傅申请验收（附照片），业主确认或提异议，全部留痕。界面不写任何“保障”“担保”字样。等和本地银行（如 Kaspi）谈好再接托管 |
| 齐家网（托管但不兑现保障，被投诉） | 托管成了信任负担 | 托管上线前先写清楚纠纷流程和时限；在那之前只承诺“记录”，不承诺“保障” |
| 吉工家（记工留住工人） | 包工头和工人双方记工时，对方会收到通知，减少工资纠纷 | **施工日志 / 记工**：师傅每天一键“今天到场 N 人”，可附照片和语音，业主那边自动收到、可确认；它同时是节点验收的依据和师傅作品集的素材 |
| 鱼泡网（看电话收费被骂、中介冒充雇主） | 打电话要充值积分 | **工人永远不为看联系方式付费**；需求方手机号验证、可举报“冒充雇主的中介”；后期加实名 |
| 酷家乐（业主自己画门槛高，转去服务设计师） | C 端留存低 | 设计保持极简（模板起步、直接输长宽），并且“从别人的图开始”让业主不必从零画；画完立即看到造价，给他画完的理由 |
| 吉工家、鱼泡（实名 + 双向评价） | 双方互评、黑名单 | 只有双方确认的合作才能互评，评价窗口结束后同时公开；评分只展示可证明的次数 |

## 4. 信息架构（已确认）

底栏：**发现 · 我的房子 · 消息 · 我的**，右上角“＋”。和 v3 相同，下面只写 v4 的改动。

| 位置 | v3 | v4 新增 |
| --- | --- | --- |
| 发现 · 房子 | 作品流 | 改名叫“图纸库”的体验：卡片右下角“用这套开始”；筛选加“已建成”“面积”“层数”“预算” |
| 发现 · 找活 | 需求卡 | 卡片显示“按清单报价 · 12 项”标签，师傅一眼知道工作量 |
| 发现 · 找人 | 名片卡 | 名片显示“已完成 N 个节点验收”“记工 N 天”这类可证明的数字 |
| “＋” | 设计 / 直接找人 / 入驻 | 第一项拆成“从零画”和“从图纸库挑一套”两个入口 |
| 我的房子 · 房子工作台 | 设计 / 找人 / 报价 / 合作 | 加第五栏 **施工**：节点进度、施工日志、验收记录、已花费 |
| 我接的活 | 按状态分组 | 进行中的活加“今天记工”按钮和“申请验收”按钮 |
| 我的 | 身份、收藏、设置 | 师傅的“作品集”从完工项目自动生成，可选择公开 |

## 5. 关键页面（v4 新增部分）

### 5.1 房子页（公开）

在 v3 的结构上加三处：

1. 标题下面一排胶囊：`已被复用 23 次` `已建成` `实际花费 2 950 万 ₸`（后两个只有完工并经房主同意才显示）。
2. 进度条改成和施工节点一致：`设计 ✓ · 找人 ✓ · 基础 ✓ · 主体 ● · 屋顶 ○ · 完工 ○`，每个已验收节点可以点开看照片（房主选择公开时）。
3. 底部操作条给访客的主按钮改为 **“用这套开始”**（原来是“收藏”），次按钮“收藏”。

```
├───────────────────────────────┤
│ ♡ 收藏         [ 用这套开始 ] │  ← 访客
│ 2 个阶段在招人    [ 去报价 ]  │  ← 有名片的师傅
│ 4 个新报价      [ 管理找人 ]  │  ← 房主
└───────────────────────────────┘
```

“用这套开始”：复制设计到“我的房子”（新名字“基于 XX 的房子”），打开设计工具并提示“改一下尺寸和房间，造价会自动更新”。原作者收到通知“你的设计被复用了”。

### 5.2 报价对比（统一清单）

```
┌──────────────────────────────────────────┐
│ 砌墙 · 186 ㎡ · 3 份报价       [只看差异] │
├────────────┬────────┬────────┬────────┤
│ 项目        │ 师傅 A │ 师傅 B │ 施工队 C│
├────────────┼────────┼────────┼────────┤
│ 外墙 42 m³  │ 18 000▼│ 21 000 │ 19 500 │  ← 每行最低价绿色
│ 内墙 12 m³  │ 16 000 │ 15 000▼│ 17 000 │
│ 过梁 14 根  │  2 500 │ 未报   │  2 200▼│  ← “未报”灰色提示
├────────────┼────────┼────────┼────────┤
│ 合计（₸）   │ 98.2万 │ 101万  │ 99.6万 │
│ 工期        │ 25 天  │ 20 天  │ 28 天  │
│ 材料        │ 仅人工 │ 仅人工 │ 包工包料⚠│ ← 范围不同，提示不可直接比
│ 评价 / 验收 │ 4.8·12 │ 新师傅 │ 4.6·31 │
├────────────┴────────┴────────┴────────┤
│        [ 和 A 聊聊 ]   [ 邀请 A 合作 ]   │
└──────────────────────────────────────────┘
```

- 清单由需求自动带出，师傅报价时只能填单价，不能改项目和数量；数量有异议时用“对此项提问”。
- 不做“推荐最低价”，只做标注。

### 5.3 合作约定：节点

约定页的“付款条件”从一段文字改成节点表：

| 节点 | 验收标准（默认模板，可改） | 金额 | 预计日期 |
| --- | --- | --- | --- |
| 基础 | 基础尺寸与图纸一致、养护满 7 天 | 20% | 11/25 |
| 主体 | 墙体到顶、过梁就位 | 40% | 12/20 |
| 屋顶 | 封顶、防水完成 | 25% | 1/15 |
| 完工 | 清理完毕、双方确认 | 15% | 1/30 |

双方各自确认整张表才生效；改任何一行都产生新版本（沿用现有约定版本机制）。

### 5.4 房子工作台 · 施工栏

```
┌───────────────────────────────┐
│ 基础 ✓ ── 主体 ● ── 屋顶 ○ ── 完工 ○ │
│ 已记录花费 39.3 万 / 约定 98.2 万    │
├───────────────────────────────┤
│ ⚑ 师傅 A 申请“主体”验收（6 张照片）│
│   [ 确认验收 ]   [ 有问题 ]         │  ← 待办，主色
├───────────────────────────────┤
│ 施工日志                            │
│ 12/18 · 到场 4 人 · 📷3 · 🎙 0:24  ✓│  ← ✓ 业主已确认
│ 12/17 · 到场 4 人 · 📷1           ○│
└───────────────────────────────┘
```

- “确认验收”只记录“业主确认该节点完成”，金额由双方线下或以后的托管支付；页面底部固定一行小字：“Yusal 目前只记录验收，不代收代付。”
- “有问题”打开带照片的异议，进入现有的变更 / 争议流程。

### 5.5 我接的活 · 进行中卡片

```
┌──────┬────────────────────────┐
│缩略图│ 草原边的两层木屋 · 砌墙  │
│      │ 主体进行中 · 第 9 天      │
│      │ [今天记工]  [申请验收]   │
└──────┴────────────────────────┘
```

“今天记工”弹出底部面板：人数（默认上次）、照片、语音备注，一次点完。

## 7. 信任与收费的原则（界面上怎么体现）

- **可证明的数字才展示**：手机号已验证、双方确认合作 N 次、节点验收 N 次、记工 N 天、有效评价 N 条。没有数据就写“新师傅”，不显示星级。
- **不写“保障”**：托管上线前，界面里没有“担保”“先行赔付”“放心付”之类的字。
- **工人免费**：找活、报名、报价、看联系方式、记工永远免费。
- **以后的收费点**（这版不做界面，只预留位置）：师傅会员（更多曝光、更多同时报价数，不卖电话）→ 建材商按工程量清单的标注推广 → 与银行合作的节点托管服务费。

## 8. 这一轮在 App 里做什么（mock 后端）

按依赖顺序：

1. 底栏 发现 / 我的房子 / 消息 / 我的 + 右上角“＋”四选一（从零画、从图纸库挑、直接找人、入驻）。
2. 发现三段：房子（图纸库，含“用这套开始”）/ 找活 / 找人，有名片的人默认进找活。
3. 房子页：复用次数胶囊、节点进度条、在招需求卡、按身份的底部操作条、“用这套开始”。
4. 我的房子：待办条、房子卡（按设计归并需求、报价、合作）、房子工作台五栏（设计 / 找人 / 报价 / 合作 / 施工）；我接的活。
5. 报价对比改为统一清单表（每行最低价标注、未报 / 范围不同提示）。
6. 合作约定加节点表；施工栏：记工、申请验收、确认 / 异议；mock 后端加 `Milestone`、`WorkLog`，接口加在 `repositories.dart`。
7. “我的”瘦身；完工自动生成作品条目。
8. 测试：底栏与默认段、用这套开始复制设计、清单对比标注、节点确认与版本、记工确认、按身份的操作条；三语文案。

不在这一轮：真实托管、实名认证、语音消息上传（先存本地占位）、建材推广、会员收费。

## 9. 需要你确认

1. **访客主按钮用“用这套开始”**（推荐，图纸库获客的核心动作），还是保持“收藏”。
2. **节点验收这一版只记录、不碰钱**（推荐），还是先在界面上展示“托管（即将上线）”占位。
3. **记工放在师傅的“我接的活”里，业主确认**（推荐），还是业主自己记。
