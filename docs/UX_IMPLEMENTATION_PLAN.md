# 自建房交互改造：实施与自评

日期：2026-09-30。用户授权自主研究、评审、实现与验证，次日早间报告实际成果。

## 产品决策

目标是首次使用也能完成房屋布局。采用：长宽创建外形 → 拉线分房 / 拖矩形划小房间 → 门窗拖到墙面 → 拖动与输入尺寸微调 → 2D / 3D 核对。模板作为可选入口；默认编辑不刷格子。高级楼层、楼梯、墙厚等保留，但避免占用初始工具栏。

不能声称绝对最优。研究证据来自官方文档与教程，并非全部软件实际操作，也没有进行真人可用性测试。自评使用明确任务与失败场景；实测可以证明功能正确，不能证明所有年龄用户的体验。

## 研究证据与取舍

此前研究包括 Floorplanner、Planner 5D、magicplan、RoomSketcher、Sweet Home 3D、Homestyler、酷家乐；来源及候选比较保存在交互研究 Canvas。补充：

- [Live Home 3D iOS 快速开始](https://www.livehome3d.com/support/guide/ios/en/)：分别覆盖矩形房间、门窗，支持矩形作为低门槛创建方式。
- [Live Home 3D Android 矩形房间](https://www.livehome3d.com/support/guide/android/en/drawing-rectangular-room)：官方具有矩形房间创建流程，不能据此推断具体手势性能。
- [HomeByMe 创建平面图](https://home.by.me/en/guide/how-to-create-floor-plan/)：外形、墙尺寸与门窗构成常见流程。
- [HomeByMe 入门教程](https://home.by.me/en/tutorials/categories/first-steps/)：包含移动端墙体与分隔操作。
- [Roomtodo 功能说明](https://roomtodo.com/features)：描图与分房方式适合已有图纸用户；不作为无图纸新用户必经入口。

结论属于设计判断：矩形外形减少闭合墙的操作；局部线分割适合大房间；矩形挖出角落适合卫生间；门窗吸附减少“先选工具、再选墙、再选类别”的步骤。拖动必须提供可见预览、撤销以及点击/输入替代。

## 数据与事务自评

现有 v1 数据是房间引用正交轴线，墙由相邻空间派生。新增局部分房轴仅属于当前楼层，同一空间内延长的轴不会自动成为墙。保持 v1 文件兼容。每次手势一个事务；预览不进历史、不落盘；双指介入或取消不提交。

全局轴移动影响所有引用，不可伪装成局部墙移动。局部移动需重新构建受影响空间边界，保护门窗与楼梯锚点。外形尺寸共用于所有楼层，必须显示影响范围。现有 300 mm 轴间距约束需要吸附与拒绝说明。

## 实施顺序与验收

1. 原子局部分房：新建矩形、角落挖房、L 形剩余空间；跨空间与楼梯冲突拒绝。核心回归测试。
2. 创建入口：长宽明确方向，不要求预先输入网格；模板次级入口。
3. 画布矩形划房与拉线分房：实时尺寸，吸附，取消，单次撤销，自动保存。
4. 门窗直接拖入：合法墙面候选、预览、失败文字说明、松手提交；点击放置替代；现有对象直接拖动。
5. 房屋外形与内墙调整：尺寸输入、可见手柄、影响提示、拒绝破坏已有对象。
6. 精简工具栏与房间用途编辑：常用功能立即可见，高级功能仍可找到；小屏与横屏不溢出。
7. 自评与交付：完整 unit/widget 测试、静态检查、iOS 模拟器流程、Web/Android/iOS 构建、截图与运行说明。

最低验收：新用户无需模板即可创建外形，拖出角落小房间，放门窗，改变尺寸，切换 3D，撤销并保存重开。两指不误建对象；非法放置不修改文档；既有项目与导入导出不回归。真实设备性能与真人研究若未做，报告明确列出。

## 实现后的自评

- 创建不强制选模板或配置网格；可输入长宽，也可在空白画布拖出矩形，未完成草绘不会写入项目。
- 拉线只分当前连通空间，框房能保留原空间为 L 形；临时拓扑与文档历史隔离。
- 门窗跟随松手位置，能跨墙移动并自动选择门朝向；非法位置或重叠取消，不误提交上一次有效预览。
- 外框拖动时冻结画布坐标变换；内墙手柄只改选中墙段，保留全局轴及其他楼层。
- 合并涉及失去宿主墙的门窗时先提示，确认后一个事务完成，撤销可恢复。
- 普通视图隐藏辅助轴格线与轴尺寸；高级网格仍可见。工具短标签配完整提示，文字放大时自适应布局。
- 自评修复了固定墙角落点、无效拖放的旧预览提交、门转窗的高度、异步 setState、菜单溢出、标签截断、辅助网格干扰及变换坐标错误。

## 仍需明确的边界

v1 仍采用正交轴、矩形外形和 300 mm 轴间距约束。与其他墙共线的局部墙细微移动可能需要至少 0.30 米；独立局部墙可以更细调整。斜墙、L 形外轮廓、自动建筑方案生成不是此次已实现功能。真人老年/青年用户研究与物理设备验收未开展，不能据模拟器和自动测试声称已经证明所有人都会使用。


## v0.3：用户补充方向的实现与验收（2026-10-01）

本轮采用用户提出的三分类浮层与连续 ➕ 绘墙。顶部轻量浮条、右侧建造/调整/查看、底部圆角 20 自适应工具卡围绕完整 2D 画布排列。动画约 200 ms，可被下一操作打断；减少动态效果时跳过切换动画。保留图标文字和数字操作替代，避免仅凭隐藏手势理解功能。

### 实施顺序

1. 先补独立墙段与 schema v2，旧房间边界一次转换，保留原宿主与房间信息。
2. 支持开放短墙、连续墙和闭合识别；统一预览、提交、撤销与保存事务。
3. 接入 ➕ 连续绘墙、端点改长、中部移动、数字尺寸和带门窗删除确认。
4. 重构浮层分类与动效，统一绘图和命中坐标，小屏、横屏、大字自适应。
5. 单元、界面、原生回归，实际截图检查，主应用三平台构建，按证据交付。

### 自评与修复

- 模型不能只由房间边界派生墙，否则无法保存未闭合短墙；新增 SolidWall 和楼层 explicitWalls，原有分房/框房工具同步实体墙。
- 旧开放区域保留房间信息；开放间隔局部补墙分割剩余间隔，不覆盖原数据。
- 房间识别按连通区域进行，移动完整分隔墙通过两侧种子保留命名房间身份。
- 临时预览使用独立随机 ID，避免与导入文件的合法 ID 冲突；不进入存储或历史。
- 原生实测发现吸附自身阻碍细微移动、短墙手柄命中区重叠；排除正在调整的轴并选择最近手柄。
- Reduce Motion 的零时长 AnimatedSize 触发布局断言；关闭动态效果时直接显示静态组件。
- 多指介入、工具切换及无效提交清理整个预览，防止中断手势继续写入。
- 连续移动清理无引用局部坐标；限制单方向局部/全局辅助坐标数，避免无限细分画布。

### 本轮边界

schema v2 独立墙坐标不再受旧式 300 mm 辅助轴间距限制，墙长仍至少 300 mm。旧 v1 规则保持兼容。当前 3D 渲染实现、矩形外形和正交墙边界不变；真人和物理设备验收仍待实际开展。最终测试数量、产物和截图见 DELIVERY_REPORT.md。
