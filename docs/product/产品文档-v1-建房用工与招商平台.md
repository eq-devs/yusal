# Yusal 产品文档 v1：建房用工与招商平台

Nov 3, 2026 · @e · 状态：草稿，待确认

## 0. 文档说明

本文档汇总了此前的定位研究、竞品调研以及讨论中确定的产品方向，用作开发前的产品规划依据。更详细的竞品材料见两份研究文档：[产品定位、竞品与未来展望](https://claude.ai/artifact/Ny3G94kjsMK5Heyah2jdkc) 和 [建房界社交社区的定位与竞品](https://claude.ai/artifact/6F24DZXqz5HyvzJRBzgSXk)。

**本版暂不包含**：材料清单直达建材商、建材电商。

## 1. 产品定位

**一句话**：Yusal 是一个建房用工与招商平台。注册后，工人可以找活，业主和包工头可以找人、发布招商，工人报名接单；普通人还可以自己设计房子、预测造价，并同步到云端。

**与同类平台的核心区别**：在别的平台上，招工或招商只是一句话；在 Yusal 上，招商帖可以直接附带设计图纸、面积、工程量和估价，工人和施工队按实际工程量报价。

**目标市场**：首发哈萨克斯坦（哈萨克语、俄语），保留中文界面。哈萨克斯坦 2024 年交付个人住宅 39,064 套，约占全部住宅套数的 23%（[Adyrna](https://adyrna.kz/post/225835)）。

### 目标用户

| 角色 | 是谁 | 最在意什么 |
| --- | --- | --- |
| 业主 | 自建房、翻新、加建的家庭 | 花多少钱、找到靠谱的人、不被骗 |
| 工人 | 瓦工、木工、焊工、电工、暖气工、抹灰工、屋面工、小工、机械司机 | 有活干、按时拿到钱、离家近 |
| 包工头 / 施工队 | 带队承接整栋房或分项工程 | 稳定接到项目、招到工人、报价快 |
| 小型开发商 / 企业 | 做小区、商铺、厂房的企业 | 发布招商、找分包方 |

## 2. 从竞品学到的五条教训

1. **工人侧必须免费**。Naimi.kz 和英国 MyBuilder 向师傅按接单收费，师傅抱怨最多；Naimi 的文字评论平均只有 2.9 分。
2. **给工人每天打开的理由**。鱼泡网（自称 6,800 万注册用户）的组合是找活名片 + 记工记账 + 工友社区。
3. **信任靠实名和资金保障，不只靠评价**。万师傅（400 万师傅）用了保证金、担保交易、保险和先行赔付。
4. **不要和通用社交拼发图**。中国家居社区好好住（巅峰 2,000 万活跃用户）于 2025 年 4 月关停，用户被小红书吸走。Yusal 要做通用平台装不下的东西：带图纸和工程量的招商、接单流程、信用记录。
5. **利用而不是对抗 WhatsApp / Instagram / TikTok**。哈萨克斯坦年轻人 WhatsApp 使用率 89%、Instagram 80%、TikTok 64%（[EnergyProm](https://energyprom.kz/en/articles-en/which-social-networks-and-messengers-do-kazakhstans-young-people-prefer/)）。每个帖子都要能一键转发出去，把人带回来。

## 3. 功能清单

### 3.1 账号与个人主页

- 手机号注册登录，选择身份：业主 / 工人 / 包工头 / 企业（可多选）。
- 工人“找活名片”：工种、经验年限、地区、日薪或按平米报价、作品照片、是否可接活。不要求写简历。
- 包工头 / 施工队主页：队伍成员、承接范围、完成的项目。
- 企业主页：营业执照信息、发布过的招商。
- 公开信息：认证标识、评分、完成单数、按时率。

### 3.2 四种帖子

| 类型 | 谁发 | 必填信息 | 可选信息 |
| --- | --- | --- | --- |
| 招工 | 业主、包工头、企业 | 工种、人数、地点、工期、工钱（日薪/按量/面议） | 食宿、开工日期、照片 |
| 找活 | 工人、施工队 | 工种、可工作地区、价格、可开始日期 | 队伍人数、作品 |
| 招商 / 招标 | 业主、企业 | 项目名称、地点、承接范围（整栋或分项）、预算区间、截止日期 | **一键附加设计项目**（图纸、面积、工程量、估价） |
| 转包 / 分包 | 包工头、企业 | 分项内容、工程量、价格、工期 | 所属项目 |

### 3.3 信息流与搜索

- 首页信息流：按身份推荐。工人默认看招工和招商，业主默认看找活和施工队。
- 筛选：地区（州/城市/村镇）、距离、工种、价格、工期、是否认证。
- 地图模式：“附近的活”“附近的人”。
- 订阅提醒：符合条件的新帖子推送通知（例如“阿拉木图州 50 公里内的瓦工活”）。
- 收藏帖子和关注人。

### 3.4 接单流程

从发布到互评的完整流程：

1. **发布**：发帖方发布招工或招商。
2. **报名 / 报价**：工人点“报名”，施工队提交报价；招商帖支持多家报价并排对比。
3. **沟通**：站内聊天，双方确认后可交换电话。
4. **确认录用**：发帖方选人，工人接受；生成一份简单的电子约定（工作内容、价格、工期、付款方式）。
5. **施工中**：可选的照片打卡和进度更新，对应设计项目里的施工阶段。
6. **完工确认**：双方确认完工。
7. **互评**：双向评价（业主评工人，工人也评业主是否按时付款）。项目自动进入工人作品集。

状态：待报名 → 沟通中 → 已录用 → 施工中 → 已完工 → 已评价；任一方可取消并说明原因。

### 3.5 信任与安全

- **实名认证**：身份证号（ИИН）+ 人脸核验；企业用БИН 认证。
- **技能认证**（后期）：证书上传、对接政府持证施工企业登记。
- **双向评价**：只有完成接单流程的双方才能互评，防止刷评。
- **举报与审核**：虚假招工、收取押金、欠薪、骚扰等举报类型；新用户前几条帖子人工审核；敏感词过滤。
- **防骗提示**：“平台不会要求工人交押金”等安全提示。
- **隐私**：电话号码默认隐藏，项目地址只显示到村镇或街区。
- **资金托管**（后期）：业主按阶段把工钱交给平台托管，验收后放给工人。需要支付牌照或与银行合作，上线前须咨询律师。

### 3.6 消息与外部分享

- 站内聊天：文字、语音、图片，可发送设计项目卡片。
- 系统通知：报名、录用、完工、评价、订阅提醒。
- 一键分享到 WhatsApp / Telegram / Instagram：生成带封面图的帖子卡片和链接，没装应用的人点开是网页，可以直接报名（注册后）。

### 3.7 设计与价格预测（已有功能的延伸）

Yusal 现有的设计工具已经包含：2D 平面、3D 外观与漫游、门窗、楼梯、屋顶、家具、工程量、预算、保温采暖、水电点位、宅基地、施工进度、设计检查和 PDF 图纸导出。平台化需要补充：

- **快速估价入口**：不画图也能估价。输入面积、层数、墙体材料、屋顶类型、地区，得出造价区间。这是吸引普通用户的第一入口。
- **地区单价库**：按州/城市维护材料和人工单价，替换现在的示例单价。
- **价格越用越准**：接单完成后郀请双方匿名提交实际成交价，用来校准地区单价；显示“本地区最近 30 天瓦工平均每平米 X 坚戈”。
- **从设计一键发招商**：把项目或其中一个施工阶段（基础、墙体、屋顶、水电暖……）发布为招商帖，自动带上工程量。
- **模板库**：常见户型（一层/两层、不同面积），可直接修改。

### 3.8 云同步

- 登录后项目自动同步到云端，换手机不丢失。
- 离线可用：沿用现有的本地保存和自动保存，联网后同步；发生冲突时保留两个版本让用户选择。
- **分享链接**：只读网页，施工队和家人不装应用也能看 3D、平面和报价。
- **共同编辑**（后期）：邀请家人或施工队一起改。
- 版本历史：可以回到之前的方案。

### 3.9 工人小工具

- **记工记账**：每天记录在哪里干、干了多少、应收多少、已收多少；可生成对账单发给雇主。
- **报价单**：选工种和工程量（或直接读取招商帖里的工程量），自动生成报价单 PDF。
- **包工头管队**：队伍成员、派工、每人工时与工资。

这些工具永久免费，是工人每天打开应用的理由。

### 3.10 管理后台

- 帖子审核、举报处理、封号。
- 认证审核。
- 地区单价库维护。
- 数据看板：注册、发帖、报名、成交、留存。

### 3.11 语言

哈萨克语、俄语、中文。俄语是新增的必须项，哈萨克斯坦大量施工队和城市用户使用俄语。

| 版本 | 目标 | 范围 |

| **MVP（v1.0）** | 在一个州跑通“发帖 → 报名 → 录用 → 互评” | 手机号注册与身份、找活名片、四种帖子、信息流与筛选、报名与录用、站内聊天、双向评价、举报与人工审核、外部分享链接、俄语界面、快速估价、云同步（单人） |

| **v1.2** | 留住工人 | 记工记账、报价单生成、包工头管队、实名认证（ИИН）、施工照片打卡 |

## 5. 商业模式

**原则**：工人基础功能永久免费，不向工人按报名或接单收费。

1. **资金托管服务费**：按托管金额收取 2%–5%（v2.0 起）。
2. **施工队 / 企业专业版订阅**：多项目管理、更多招商帖、主页认证标识、数据统计。
3. **置顶与加急**：招工/招商帖付费置顶。与普通帖子明确区分并标注“推广”。
4. **专业服务**（v2.x）：审图、报批协助、保险和贷款的渠道费。

MVP 阶段建议全部免费，先把交易量做起来。

## 6. 冷启动与推广

1. **选一个州或城市起步**（例如阿拉木图周边），帖子密度比全国覆盖更重要。
2. **先拉工人和包工头**：线下走访劳务市场、建材市场和在建工地，帮前 100 位工人填好找活名片。
3. **搬运已有需求**：在用户同意的前提下，帮包工头把他们在 WhatsApp 群和 OLX 上发的招工信息发到 Yusal，并把 Yusal 链接转回群里。
4. **用快速估价吸引业主**：在 Instagram / TikTok 投放“输入面积，30 秒知道盖房要多少钱”类内容。
5. **与本地建房博主合作**，让他们用 Yusal 设计和招人并记录过程。

## 8. 技术影响

现在的 Yusal 是一个纯本地的 Flutter 应用，没有账号和后端。平台化需要新增：

- **后端服务**：账号、帖子、报名/订单状态、评价、聊天、通知、举报与审核。仓库已配置 Firebase Hosting，可以考虑先用 Firebase（Auth、Firestore、Storage、Cloud Messaging）快速验证，但要确认哈萨克斯坦的数据本地化要求。
- **云同步**：现有 `.house` 文件是 JSON，可以直接上传存储；需要设计冲突处理和版本历史。
- **网页端分享页**：仓库已支持 Flutter Web，可用于只读的项目和帖子页面。
- **短信验证、地图、推送**等第三方服务。
- **应用结构**：首页从“我的设计”变成“信息流 / 消息 / 发布 / 我的设计 / 我的”五个标签。现有设计工具作为“我的设计”保留。

## 9. 风险

1. **双边冷启动**：没有工人就没有业主，反之亦然。对策是地域集中、先拉工人、线下推广。
2. **虚假信息与诈骗**：同类平台的通病。对策是实名、审核、举报和防骗提示。
3. **私下交易**：双方联系上后不再使用平台。对策是让平台提供离开就没有的价值（评价、作品集、记账、资金托管）。
4. **法律合规**：用工中介资质、资金托管牌照、个人数据保护、平台对纠纷的责任。上线前咨询哈萨克斯坦本地律师。
5. **价格预测的准确性**：用户可能按估价做决定。需要标注“仅供参考”，并显示价格区间而不是单一数字。
6. **开发量**：平台功能的工作量大于现有设计工具。MVP 要严格控制范围。
